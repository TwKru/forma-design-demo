# NOVUS event concept

Independent static website design concept by Timofey. Not an official event website and not affiliated with NOVUS Design Community. Existing demos are unchanged.

The public project request mentioned Saint Petersburg and 9 December. The 2026 year follows the current project context. Exact venue, event time, official program, ticket prices and speakers were not supplied. The sample agenda is explicitly marked as fictional demonstration content. No real reservations, payments, marketing subscriptions or contact requests are processed.

## Features

- Responsive editorial design with orange and chrome art.
- Program filtering, expandable session descriptions, locally saved session selection and reset.
- Registration dialog with field validation and a clearly invalid demonstration ticket. Personal fields remain in memory only and are cleared when the dialog closes.
- Native canvas artwork, responsive navigation, scroll reveals and reduced-motion support.
- No third-party runtime libraries, trackers, remote fonts or form backend.

## Assets

Golos Text and Unbounded fonts use the SIL Open Font License. The exact license texts are included in `assets/`.

The main image `assets/hero.jpg` was generated with the built-in image generation tool, not the CLI. It is an artistic rendering, not a photograph of an actual event. The PNG was encoded as JPEG for web delivery without compositional edits. Full final prompt and mode: [assets/hero-prompt.txt](assets/hero-prompt.txt).

## Local preview

Run a static HTTP server in this directory. No build or package installation is required. GitHub Pages hosts the public demo. Do not add credentials, private lead research or customer data to this repository.
